For a while, this site was just a single static page, hosted for free on GitHub Pages. It did the job, but it never really changed, no easy way to add anything new without editing raw HTML by hand.

I wanted two things: a place to share short updates, project notes, RPG session reports, links to things I'm testing; and a reason to actually practice coding.

So I rebuilt it. The site is now generated by a small Python script. I can write posts as plain text files with a bit of Markdown formatting, the script turns them into proper web pages, and adding a new post is just: create a file, run one command.

Instead of GitHub Pages, the site now runs on an Apache container on my own homelab. That means I'm responsible for the whole chain myself, installing Python properly, managing dependencies, running the web server, keeping git in sync between my Laptop, PC and the server. It's more work than GitHub Pages was, and I've already run into my share of small, annoying problems along the way, caching issues, a stray typo that broke the build, a browser quirk that only showed up on my phone. But that's really the point. Reading about running a web server and actually running one are two different skills.

The result is still simple on purpose: a homepage, a handful of themed sections matching what I already care about: security, quality management, and learning, plus music, tabletop games, and homelab on the personal side, and posts that show up under whichever of those they belong to. Small, but mine, end to end.
